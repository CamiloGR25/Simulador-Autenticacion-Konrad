SIMULADOR PRÁCTICO

Recupera la seguridad de una aplicación Angular

Te incorporas como desarrollador web a un equipo que está preparando el lanzamiento de una aplicación. Durante las pruebas se detectaron problemas en el inicio de sesión, los tokens, las rutas protegidas, la sesión y la comunicación con la API.

Tu misión será identificar las fallas, modificar configuraciones, completar código y ejecutar pruebas hasta conseguir que únicamente los usuarios autorizados accedan a los recursos.

Angular→Login→JWT→ Guard→Ruta protegida→ HTTP→CORS→API

[ALERTA] /admin permite acceso incorrecto

[ALERTA] solicitud bloqueada por CORS

OBJETIVO:
resolver 6 incidentes de seguridad
sin quedar bloqueado en el proceso.

Aprender haciendo

Escribirás código, completarás cabeceras HTTP, inspeccionarás tokens y ejecutarás pruebas.

Error seguro

Puedes probar, equivocarte, reiniciar una misión y volver a ejecutar sin afectar ningún sistema real.

Pistas progresivas

El botón “Pista / Ayuda” está disponible en todas las misiones y ofrece hasta tres niveles de apoyo.

MISIÓN 04

Programa el Guard de Angular

Solo un usuario autenticado con rol admin debe acceder a /admin.

Pendiente

admin.guard.ts

Pruebas automáticas

○ No autenticado → BLOQUEADO
○ Autenticado / user → BLOQUEADO
○ Autenticado / admin → PERMITIDO
Escribe la condición y ejecuta la batería de pruebas.
El simulador analiza la estructura de tu solución; no ejecuta TypeScript arbitrario.
